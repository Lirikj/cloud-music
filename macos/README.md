# Cloud Music для macOS

Нативный музыкальный плеер на SwiftUI / AppKit / AVFoundation, версия 1.1.0 (build 2). Интерфейс реализован по макету «Коллекция»: боковая навигация, обложки, очередь справа, постоянный плеер и отдельный экран текущего трека. Обе темы, системное оформление и плавные переходы с поддержкой Reduce Motion. macOS 13+, Apple Silicon и Intel.

Публичная папка Яндекс Диска подключается по ссылке; поддержаны подпапки и постраничное чтение. Google Drive использует публичное embeddedfolderview и веб-загрузку с формой подтверждения; закрытые папки, вход в Google и обход квот не реализованы. Структура веб-страниц Google может меняться. Метаданные облачных треков определяются из имени «Исполнитель - Название»; альбом — из папки. Для плоских папок обложки объединяются в коллекции по исполнителям; для подпапок сохраняется их название. Избранное, поиск и очередь выбранного исполнителя/коллекции сохраняют контекст коллекции.

Локальные файлы и папки выбираются через NSOpenPanel, читаются без копирования, сохраняются security-scoped bookmarks. Поддержаны папки, отдельные файлы и открытие аудио через Finder. Воспроизводятся форматы, поддерживаемые AVFoundation данной версии macOS; наличие расширения в библиотеке само по себе не означает поддержку кодека (например, некоторые OGG/Opus/WMA).

Автоматического сохранения музыки нет. Пользователь явно выбирает «Скачать на Mac» и папку назначения; файлы помещаются в её подпапку Cloud Music, доступны в «На этом Mac» → «Скачанные треки» и используются вместо облачного оригинала при запуске. Есть прогресс, отмена, повтор, удаление отдельной копии. При отключении источника сохранённые копии остаются; исходные облачные и выбранные локальные файлы не удаляются.

В плеере: перемотка, предыдущий/следующий, повтор, случайный порядок, очередь, громкость, системные команды Now Playing. AVPlayer начинает воспроизведение без искусственного таймера подготовки; предпочитаемый запас буфера — 8 секунд. Это рекомендация системному плееру, а не строгий предел памяти. Время старта и непрерывность зависят от облака, кодека, сети и VPN; перекодирования на низкий битрейт нет.

Обложки MP3/FLAC читаются ограниченными запросами (до 4 МиБ, не более двух одновременно), локальные метаданные — через AVFoundation. Кэш изображений ограничен 4 МиБ на диске и 4 МиБ в NSCache (системная рекомендация лимита); миниатюры до 384 px. При загрузке аудио фоновые запросы обложек отменяются. Сначала читается 32 КиБ, затем только нужный размер метаданных; при сетевой ошибке предусмотрены две повторные попытки с задержкой и обновлением временной ссылки. RAM-декодирование и дисковые чтения выполняются вне тела SwiftUI View, поэтому прокрутка и таймер плеера не запускают повторную работу всей медиатеки. Кэш можно очистить в настройках.

Список треков, исполнителей, альбомов и скачанных файлов индексируется один раз на изменение библиотеки; поиск и переключение разделов используют кэшированные результаты. Таймер позиции обновляет только транспорт плеера с частотой четыре раза в секунду. Встроенные анимации ограничены переходами страниц, очереди, появлениями обложек и состояниями нажатия; при включённом Reduce Motion они сокращаются.

Библиотека — `~/Library/Application Support/Cloud Music/library.json`; пользовательские настройки — отдельный suite UserDefaults. Собственного сервера, аккаунта, телеметрии и сторонних SDK нет. При подключении облака сетевые запросы идут к выбранному провайдеру. Ярлыки с временными подписанными URL хранятся до четырёх минут в RAM, не более 512 записей.

## Сборка

Swift 5.10+, Command Line Tools / macOS SDK. Полный Xcode не обязателен; сторонних пакетов нет.

```sh
./scripts/build.sh
```

Создаёт Universal `.app` в `dist/Cloud Music.app`. Для одной архитектуры: `UNIVERSAL=0 ./scripts/build.sh`. Для разработки: `CONFIGURATION=debug UNIVERSAL=0 ./scripts/build.sh`.

По умолчанию сборка подписана локальной ad-hoc подписью. Для обычного распространения с Developer ID задайте `DEVELOPER_ID_IDENTITY`, затем выполните нотарификацию Apple и stapling отдельными инструментами; учётные данные в проект не входят. Без Developer ID/notarization macOS может показать предупреждение о разработчике при получении приложения с другого компьютера. Защитные настройки macOS сборка не меняет.

## Проверки

```sh
swift build -j 2
.build/debug/cloud-music-check --self-test
.build/debug/cloud-music-check --folder 'https://disk.yandex.ru/d/EXAMPLE' --play
```

Самопроверки выполняются отдельным исполняемым модулем и не требуют XCTest из полного Xcode. Проверяют ссылки, имена, разбор Google, границы обложек и сохранение библиотеки. `--play` проверяет реальный AVPlayer и перемотку; облачные файлы не изменяет. Для изолированной ручной проверки запускайте приложение с `--library-directory /absolute/test/directory`, чтобы не использовать основную библиотеку. Встроенное демо — три оригинальных синтезированных звука, добавляется только по кнопке и явно подписано как локальное. В приложении нет предзаполненной папки: пользователь сам нажимает «Добавить папку» и вставляет ссылку или выбирает каталог на Mac.

Документация: [AVPlayer](https://developer.apple.com/documentation/avfoundation/avplayer), [NSOpenPanel](https://developer.apple.com/documentation/appkit/nsopenpanel), [App signing](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).

Сетевые фикстуры: запустите `python3 scripts/fixture-server.py`, затем передайте выведенный порт в `cloud-music-check --fixture http://127.0.0.1:PORT`. Проверяются пагинация, подпапки, ограничение ответа без Range, ошибки доступа, целостность скачивания и отмена.

Для сквозной проверки моделей самого приложения: `scripts/check-models.sh /absolute/fresh-qa-library /absolute/demo-fixtures`. Фикстуры создаются `python3 scripts/make-demo.py /absolute/demo-fixtures`. Проверка читает реальную публичную папку, воспроизводит аудио с нулевой громкостью, скачивает одну тестовую копию и удаляет её после проверки офлайн-режима; настройки сети компьютера не меняет. Используйте новую отдельную библиотеку.

Результаты заключительной проверки и ограничения текущей сборки: [VALIDATION.md](VALIDATION.md).
