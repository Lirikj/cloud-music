# Cloud Music 0.3.1 release — проверка 16.10.2026

Настоящий подписанный пользовательский release APK: `app.cloudmusic`, versionCode 5, Android 8.0+ (minSdk 26), targetSdk 35. Отладка и testOnly выключены. Код оптимизирован и обфусцирован R8, неиспользуемые ресурсы удалены. Режимы разработки и тестовый QA APK в пользовательский APK не включены.

## Артефакт и подпись

- APK: **4 084 716 байт**, вместо 22 871 094 байт у debug 0.3.0; уменьшение на **82,1%**. Это уменьшение установочного файла, а не обещание такого же изменения RAM или сетевой скорости.
- SHA-256 APK: `e907ce89b1928f7884403882cbbf80c68f9809268372746380ed7728ac19391b`.
- Подпись: **CN=Cloud Music, O=Cloud Music**, RSA 3072, проверена APK Signature Scheme v2.
- SHA-256 сертификата: `d35c6ad5c5bcfe6042929e2a8dfd46541d4299688d92e76ebaaf011ad978e76e`.
- `zipalign -c -P 16 4` прошёл. Это проверка упаковки, а не отдельный прогон на устройстве с размером страницы 16 КиБ.
- Android подтвердил отсутствие DEBUGGABLE и TEST_ONLY; `run-as app.cloudmusic` отказал с `package not debuggable`.
- Подписанный AAB также собран, публикация в магазине не выполнялась.

Приватный ключ сохранён отдельно от outputs и исходного ZIP с ограниченными правами доступа. Пароли и keystore не входят в исходники. Для будущих обновлений нужен тот же ключ; конфигурация задаётся через `CLOUD_MUSIC_SIGNING_PROPERTIES` или локальный игнорируемый `signing.properties`.

## Проверки

Финальная команда `assembleRelease bundleRelease testReleaseUnitTest lintRelease` прошла. **17 JVM-тестов, 0 ошибок**. Lint: **0 ошибок, 3 предупреждения** (закреплённая зависимость, квалификатор v26, монохромный слой в отдельном v33-ресурсе).

Готовый APK установлен на отдельный Android 15 / API 35 ARM64 эмулятор, 720×1600, 2 ГиБ RAM, 2 ядра. Проверялся именно APK с указанной выше контрольной суммой. Анимации включены. **3 сценария через системный интерфейс, 0 ошибок, 79.941 с**:

1. Подключение предоставленной папки Яндекс Диска (256 треков), поиск и запуск `347aidan — Dancing in My Room`, продвижение позиции после Home, перемотка. Скачивание через меню, отображение готовой копии; выключение Wi-Fi и мобильной сети, полный перезапуск процесса, повторный запуск исходного облачного трека через сохранённый файл и перемотка на 35 секунд. Удаление скачанной копии через интерфейс.
2. Системный выбор локальной папки с двумя оригинальными тестовыми WAV, фильтр по `QA Artist`, системная очередь из двух треков. Воспроизведение и перемотка локального файла при отключённых сетях.
3. Восемь открытий/сворачиваний плеера, светлая и тёмная темы, очередь, адаптивная иконка, проверка флагов установленного приложения.

Проверки выполняет отдельный процесс `release-qa`, который не импортирует внутренние классы приложения и не меняет R8-правила APK. Прежние 17 внутренних инструментальных тестов относятся к debug-варианту; их результаты 0.3.0 сохранены в `VALIDATION-0.3.0.md`, они не выдаются за прогон оптимизированного APK. Прямая попытка запустить их внутри minified release выявила несовместимость тестового classpath; для release используется проверка через системный интерфейс.

После финального прогона crash-буфер пуст. Нативные скриншоты плеера обеих тем, скачивания, локальной музыки и исполнителя просмотрены. Тестовая скачанная копия удалена; облачные оригиналы не изменялись.

## Установка и ограничения

У debug 0.3.0 и прежних версий другая подпись. Обновление поверх них не поддерживается Android: потребуется удалить debug-приложение и установить release заново. Удаление стирает внутреннюю библиотеку, избранное, настройки и разрешения локальных папок. Сохраните ссылки и нужную информацию заранее, затем подключите источники заново. Оригинальные облачные файлы и выбранные локальные файлы не стираются. Файлы общей папки Downloads/Cloud Music можно подключить через «Папки» → «На устройстве»; старый внутренний индекс загрузок не переносится.

Физический телефон, его VPN, динамик и Bluetooth не проверялись. Эмулятор подтверждает декодирование, позицию, состояние медиасессии и интерфейс. Сетевая скорость всё ещё зависит от соединения и облака; release-оптимизация не устраняет ограничения Яндекс Диска. Google Drive не получил новой живой проверки. Android 8–9 и длительное ожидание сети DownloadManager отдельно не прогонялись.
